# v0.8.5 — 纯净对话模式 + 手机飞书同步

> 这次有两个大功能：
> **① 纯净对话模式**——把 AI 网页收起来，只留一个干净的对话界面（类 Codex / Claude Code）；
> **② 飞书同步**——电脑上跑的对话，手机上也能看、能回。

---

## 🧊 纯净对话模式（Harness）

按 **`Ctrl+Shift+H`**（或菜单「查看 → 纯净对话模式」），AI 网页退到后台，换成纯对话界面：

- **只显示你关心的**：你的消息、AI 的回复、工具调用卡片
- **看不见底层噪音**：系统提示词、工具结果回传、格式纠正提示——全部隐藏
- 工具调用变成**卡片**：名称 + 参数 + 状态，成功了自动折叠

### 还带了这些

| 功能 | 说明 |
|---|---|
| **流式输出** | 回复逐字出现，带光标；思考过程单独折叠块 |
| **🎯 目标（/goal）** | 输入 `/goal 目标`，AI 自动多轮推进；发 `[[GOAL_DONE]]` 表示完成；最多 15 轮；可随时停 |
| **📋 计划** | 复用 todoWrite，顶部折叠面板显示进度（待办/进行中/完成） |
| **斜杠菜单** | 输入 `/` 弹出菜单，↑↓ 选、Enter 确认、边打边过滤 |

UI 是 **Claude Code 风格**：深色极简、暖色点缀、图标全内联 SVG。

> 💡 不用纯净模式时**不占资源**——视图首次进入才创建，平时零开销。

## 📱 飞书同步（手机收发对话）

让**手机飞书**也能跟进电脑上的对话：

- **电脑 → 手机**：你发的消息、AI 回复、工具调用状态，都推到飞书
- **手机 → 电脑**：在飞书群里发消息（可直接发，**不用 @**），就送到对应的窗口发给 AI

### 怎么用

1. 建一个飞书应用（免费），按 **内置图文教程** 一步步配（侧边栏「飞书」页里有链接，5~10 分钟）
2. 建个飞书群，把机器人拉进去
3. Estrix 里，每个**窗口**选一个群绑定

**每个窗口绑各自的群**——开多个窗口互不干扰，消息不会串。

### 贴心设计

- **连接用长连接**：不需要公网 IP、不需要服务器，普通电脑直接可用
- **保护隐私**：工具调用只发"调用中 / 完成"两条状态，**默认不带工具名、不带参数、不带结果**
- **内置图文教程**：应用内新窗口打开，**离线也能看**
