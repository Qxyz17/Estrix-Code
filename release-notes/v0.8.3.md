# v0.8.3 — 全新侧边栏 UI

> 本次是 **UI 的大重构**：把原来"塞在 AI 网页里的悬浮面板"，改成了 **VS Code 风格的独立侧边栏**。
> 位置在地址栏下方、AI 页面左侧，信息更清晰、操作更顺手。

---

## ✨ 全新侧边栏

侧边栏在最左侧，一列图标切换 7 个页面：

| 图标 | 页面 | 能做什么 |
|---|---|---|
| ⚡ | **提示词** | 管理快捷提示词，一点填入输入框 |
| 🔧 | **技能** | 看有哪些技能，点击让 AI 用它 |
| 🔗 | **MCP（连接器）** | 看已连接的 MCP，点击引用 |
| 🪟 | **窗口** | 新建 / 切换 / 删除窗口 |
| 元 | **Token** | 用量统计 + 自动压缩 + 近 10 日柱状图 |
| ⚙️ | **设置** | 重试 / 发送延迟 / 附件间隔 |
| ℹ️ | **关于** | 版本、检查更新、开源地址、QQ 群 |

**可收起**：点当前图标收起，只留一列图标栏（默认收起，界面更清爽）。

---

## ⚡ 快捷提示词

自己攒一批常用指令，点一下就填进输入框：

- 内置 3 条（生成项目说明 / 沉浸式交流 / 卡住了?点我）
- **想加就加、想改就改、想删就删**
- 每条可设「**自动发送**」开关：开了立即发出，关了只填入、你再补充

---

## 📦 地址栏也能选项目了

地址栏最左边显示当前项目目录（首字母图标 + 名字），**点一下就能重新选目录**。

---

## 🔧 其它改进

- **深浅色跟随系统**：白天白底、晚上深底，自动切换
- **工具执行更清爽**：提示条移到页面顶部，不挡内容；执行时不能点页面但**能滚动**
- 所有弹窗换成**统一风格**（不再用系统原生的丑陋弹框）

---

## 🗑️ 简化

- 去掉了 AI 页面里那个**悬浮球（右下角 C）**和旧的悬浮面板——功能都搬到侧边栏了
- 去掉了地址栏下方的 token 小条（数据在「Token」页看）

---

## 📦 安装

- **Windows**：下载 \`estrix-code-win-v0.8.3.exe\`（安装版）或 portable 版。
- **macOS**：下载对应架构的 \`.dmg\`（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.8.x 用户：启动后稍等会收到自动更新提示；也可到「关于 → 检查更新」。
