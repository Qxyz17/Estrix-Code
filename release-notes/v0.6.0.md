# v0.6.0 — 架构重构版

> 这是一次**架构级重构**，不是普通功能版。全仓 TypeScript + ESM + 目录按领域重组 + 工具契约自动生成。
> 对使用者而言：**功能照旧，但更稳、更快、更好维护**；同时带来几个新特性。

---

## ✨ 新增功能

- **窗口地址栏**：窗口顶部新增地址栏，可查看/复制当前网址、粘贴网址跳转，支持前进 / 后退 / 刷新 / 主页。
  （底层改用 `WebContentsView` 架构：地址栏与 AI 页面分离，互不干扰。）

- **工具调用执行遮罩**：AI 执行工具期间，页面会显示遮罩「工具调用执行中，请不要有额外操作」，
  避免你在此期间误触发送/切会话导致流程错乱。执行结束自动移除（失败也会移除，不会锁死页面）。

- **AI 回复中断自动重试**：当服务端把回复标记为「已停止」但正文没生成完（截断）时，
  自动按退避间隔重发上一条提问，不再无声中断。可在设置里配置间隔与次数。

## 🚀 底层重构（对稳定性与后续开发影响最大）

### 全仓 TypeScript
- 所有源码由 JavaScript 迁移到 TypeScript，**主应用开启 strict 模式**（类型错误 0）。
- 编译产物输出到 `out/`。
- hook（网络拦截器）作为**独立类型环境**单独配置（它是注入浏览器主世界的动态脚本，性质不同）。

### 全面转向 ESM
- 统一使用 ES 模块，原生动态 `import()`。

### 目录按领域重组
- 由原先的 `main / preload / utils / tools` 分层，改为按职责分领域：
  `app（外壳）/ session（会话）/ bridge（桥接）/ overlay（UI）/ tools（工具）/ providers（平台）/ mcp / infra（基础设施）`。
- 依赖方向明确（`infra ← providers ← tools ← bridge ← session ← app`），消除跨层反向依赖。

### 工具 API 契约自动生成
- **每个工具成为唯一真相源**：改一个工具，其 API 契约（给 AI 的 `api.d.ts`）、
  沙箱注入代码（`bootstrap.generated.ts`）、提示词章节**全自动同步**。
- 加新工具时不再需要手改多处、也不易漏改。

### Provider hook 模块化
- 三个平台（DeepSeek / Claude / ChatGPT）的网络拦截器改为正常 TS 模块，
  构建期用 esbuild 打包成自包含字符串，**消除三平台重复的 SSE 解码代码**。

### 工具调用模式收敛
- 仅保留 JS（`estrix` 代码块）一种调用方式；旧的 JSON 工具调用格式不再执行（仅识别并提示 AI 改用新格式）。

### 依赖升级
- Electron 33 → **44**、TypeScript 5 → **7**、ESLint 9 → **10** 等。
