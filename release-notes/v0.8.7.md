# v0.8.7 — 工作区 + AI 自动命名 + 一批修复

> 这次主要是**侧边栏「工作区」**（按项目分组管理所有对话）+ **AI 自动给对话命名**，
> 外加十几个修复。

---

## 📁 侧边栏「工作区」（新）

左侧新增「工作区」页：**按项目目录分组**，列出你所有对话。

- **分组**：每个项目一个组，组内按时间倒序
- **点对话** → 直接跳过去
- **悬停对话** → 出现 **重命名** / **归档** 按钮
- **悬停项目** → 出现 **新建对话** / **归档项目** 按钮
  - **新建**：用该项目**直接开新对话**（自动选好项目、发初始化提示词，不弹目录框）
  - **归档项目**：收到列表底部「已归档 N 项目」（折叠）
- **悬停项目名** → 信息卡片（**完整路径** + **创建时间**）
- 已归档的对话收在每个项目下的「已归档 N 对话」（折叠）

---

## ✨ AI 自动给对话命名（新）

对话标题不再是那串看不懂的会话 ID —— **AI 会在对话开始时自动起个名字**（如"修复登录 bug"），显示在工作区列表里。

> 你也可以在工作区里**手动重命名**。

---

## 🧊 纯净对话模式（增强）

- **顶部按钮切换**：地址栏「项目选择」右边新增「**纯净模式 / 原版模式**」按钮（不用记快捷键了）
- **跟随系统深浅色**：纯净模式现在**浅色/深色都支持**（跟侧边栏一致），不再固定深色
- **Markdown 渲染大升级**：改用成熟的 markdown 解析器，**标题 / 表格 / 链接 / 引用 / 有序列表 / 任务列表** 都能正常显示了
- **首次对话提示**：新对话还没选项目时，输入框变成一个大按钮「**首次对话需选择项目目录**」，点了直接选目录

---

## 📊 底部状态栏 + 最近使用

- 窗口底部显示「**对话上下文: xx**」（当前占用的 token）
- 旁边一排**最近使用**的快捷入口（技能 / MCP / 子代理 / 提示词，**彩色标签**），点一下直接调用
- 最多保留 5 条，关窗也不丢

---

## 🤖 侧边栏「子代理」页（新）

管理子代理：列出（用户级 / 项目级）、新建（生成模板 + 打开编辑）、改名、删除。

---

## 🐛 修复

- **空回复重试**：AI 回复正文为空时，现在会**判为失败并自动重试**（三个平台统一）
- **网页抓取**：修复 Bing 等"头部脚本多"的网站**只返回标题**的问题（改为先转 Markdown 再截断）
- **User-Agent**：改为**动态取真实内核版本**（修复写死旧版本导致的 Google 登录被拒）
- **提示词页一直"加载中"**：修复 API 名写错的 bug
- **底部状态栏被网页盖住**：修复 AI 页面高度算错（多算菜单栏）导致底部状态栏只露出一条
- **子代理残留文件**：子代理窗口不再产生无用的存储文件（并自动清理历史的）

---

## ⚠️ 安装说明（重要变化）

- **Windows**：从本版起**只提供安装版**（`estrix-code-win-v0.8.7.exe`）。
  **不再提供便携版（portable）/ zip 版**——因为它们**无法自动更新**，长期用会错过修复。
  已有便携版用户请**换用安装版**。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。

> 已有 0.8.x 用户：启动后稍等会收到自动更新提示；也可到「关于 → 检查更新」。
