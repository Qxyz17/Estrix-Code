# v0.8.1 — MCP 项目级配置 + 连接池

> 本次把 **MCP 配置对齐 Claude Code**：支持**项目级**和**用户级**两套配置，不同项目可以有不同的 MCP。
> 同时修正了「今日窗口」token 统计口径、修了一个让压缩失败的隐蔽问题。

---

## ✨ 新增

### MCP 支持项目级配置 · 0.8.1

以前 MCP 配置是**全局一份**，所有项目共用。现在分成两层：

- **用户级** `~/.estrix/mcp.json` —— 所有项目都能用（适合通用的，比如浏览器、记忆）
- **项目级** `<你的项目>/.estrix/mcp.json` —— **只在这个项目里生效**（适合项目专属的，比如特定数据库）

**同名时项目级优先**。MCP 面板的列表里，每个 server 都会标明来源（「用户」/「项目」）。

> **已有配置会自动迁移**：首次启动时，旧的全局配置会被自动复制到用户级（旧文件保留，不删）。

### MCP 连接池 · 0.8.1

多个窗口共用一个 MCP 时，**只启动一个进程**，不重复占资源。
关掉窗口 / 切换项目时，不再需要的连接会自动释放（闲置 60 秒后断开）。
退出应用时，所有 MCP 进程会一并清理。

## 🔧 改进

- **「今日窗口」token 口径修正** · 0.8.1：之前跨天会少算，现在改为**累加今天每一轮的完整消耗**（过午夜自动归零）。
- **发送延迟不再限制 10 秒** · 0.8.1：设置里的「发送延迟最大值」之前最多只能填 10 秒，现在**上限取消**。
- **MCP 面板 JSON 编辑框只管用户级** · 0.8.1：避免把项目级配置误写进全局。

---

## 🐛 修复

- **压缩失败** · 0.8.1：修了一个隐蔽问题——DeepSeek 有时不发送"完成"信号，正文其实已经生成完了，但被误判为失败，导致压缩一直等到超时（120 秒）。现在会正确识别为完成。
- **测试污染用户目录** · 0.8.1：修复测试会写入真实用户配置的问题（改用隔离变量）。

## 📦 安装

- **Windows**：下载 `estrix-code-win-v0.8.1.exe`（安装版）或 portable 版。
- **macOS**：下载对应架构的 `.dmg`（Intel 选 x64，Apple Silicon 选 arm64）。
