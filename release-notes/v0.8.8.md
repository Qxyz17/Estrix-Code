## 🧩 插件市场（全新）

侧边栏新增「**插件**」页——像 VS Code 扩展市场一样，**一键装别人做好的能力包**。

- **自动发现**：列出 GitHub 上所有打了 `estrix-plugin` 标签的仓库（名称 / 简介 / star / 更新时间）
- **一键安装**：下载 → 解压 → **自动生效**（不用自己找文件、对目录）
- **管理**：已安装列表、卸载、启用/禁用开关
- 一个插件可以打包：**技能 / 代理 / 规则 / MCP 配置 / 自定义平台**
- **安全**：可执行内容默认不装，需你**显式授权**；解压拒绝危险路径（防路径穿越）

---

## 🧊 纯净对话模式（大升级）

- **多会话隔离**：切换对话时，**历史 / 目标 / 计划各归各的**，不再串会话
- **侧栏「对话」分页**：实时读取网页端的会话列表，可**切换 / 新建 / 刷新**（此入口暂时隐藏，下版开放）
- **数学公式渲染**：支持 **LaTeX 数学公式**（行内 + 块级，离线内置，不联网）
- **Markdown 增强**：表格、多级标题、列表、引用、删除线都能正常显示
- **目标（/goal）自动推进**：目标完成由 AI 显式调用工具收束，不再靠"猜"
- 一堆**稳定性修复**：对话流空白、状态卡在"运行中"、导航后上报失效等（详见下）

---

## 📁 工作区（会话血缘）

对话现在**可以展开**，看到它的"**亲戚**"：

- **子代理**：这个对话调用过哪些子代理（展开可见）
- **压缩历史**：对话被压缩过的旧版本（展开可见）
- 两个分组都可**折叠/展开**，默认收起
- **压缩后子代理不丢**：即使对话压缩了，之前调用的子代理**依然能看到**

## 🎨 其他改进

## 🐛 修复

- **纯净模式：对话流空白 + 状态永久卡在"运行中"**：定位根因（上报门控判断错就整片哑掉），彻底删除门控
- **纯净模式：网页答完仍显示"运行中"**：改用权威结束信号，不再靠超时猜
- **纯净模式：页面导航后上报失效**：彻底移除门控，系统提示词改由主进程直推
- **纯净模式下框架消息无反馈**：系统提示词、工具结果回传等会在状态栏显示来源，并阻止插话
- **DeepSeek 限流检测**：识别"频率过快"文案，按操作频繁处理；429 重试默认值调整（120s / 40 次）
- **停止后仍自动发送**：先下发停止信号，修复停止后消息仍在发的问题
- **"思考中…"悬留**：工具回合/思考回合正确收尾
