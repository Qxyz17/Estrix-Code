## 📂 文件预览（Monaco Editor）

侧栏「文件」页点文件 → **树右侧**显示文件内容，**不覆盖 AI**：

- **VSCode 同款编辑器**（Monaco）：行号 + 语法高亮
- **左条拖拽**：调整文件树宽度（总宽不变，AI 不动）
- **右条拖拽**：调整侧栏总宽（树不变，内容伸缩）
- **切走 tab / 收起侧栏** → 临时隐藏（记住文件）；**切回**自动恢复；**点 ✕** 真关闭
- 修复：侧栏越开越宽的问题（基础宽用稳定存储值 + clamp 75% + 保证 AI 至少留 300px）

## ⚡ 输出速度（TPS）

状态栏实时显示模型**输出速度**（tokens/秒）：

- **DeepSeek**：用服务端返回的精确 token 数
- **ChatGPT / Claude**：估算
- 仅在**生成中**显示，空闲时隐藏

（**@8555uuy**，PR #33）

## 🔌 插件增强

- **`scripts/` 贡献类型（新）**：插件可按 URL 匹配向网页主世界注入脚本，可作用于内置平台。（**@jiangchengnay**，PR #26）
- **插件市场支持 Gitee 源**：国内访问 GitHub 不稳定时，可用 Gitee 检索/下载/安装插件（`gitee:owner/repo`）。（**@jiangchengnay**，PR #28）
- **`transformToolResult` 钩子（新）**：provider 可在工具结果回传前自定义文本格式（插件可自适配敏感平台）。（**@8555uuy**，PR #34）

---

## 🛡️ webFetch SSRF 防护（设置开关）

设置页新增「**网络安全**」→「**拒绝 webFetch 访问内网/本地地址**」（**默认关闭**）：

- **关闭（默认）**：可访问任意 http/https（含本地项目）
- **开启**：拒绝访问内网、回环、链路本地、保留地址（防 SSRF 攻击）

> 修复：不拦 `198.18.0.0/15`（Clash/V2Ray 等代理 fake-ip 默认段），避免开启后公网域名被误判。

（**@8555uuy**，PR #32）

## 🐛 修复

- **危险命令检测**：修复复合命令（`&&` `||` `;` `|` `&`）绕过检测；统一为单一真相源并补充危险变体。（**@8555uuy**，PR #30）
- **glob**：未指定 path 时默认排除 `node_modules` 等产物目录，避免淹没项目自身文件；结果附"被忽略目录"提示。（**@8555uuy**，PR #31）
- **子代理**：修复在豆包等 contenteditable 平台卡在"发送任务提示词"（填充后校验 + 失败重试）。（**@jiangchengnay**，PR #29）
- **设置保存**：修复点保存报"目标最大迭代次数必须是正整数"（该字段属纯净模式自管）。
