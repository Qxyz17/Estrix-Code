# v0.8.9 — 窗口组（多账号限流轮换）

本次亮点速览：

1. **窗口组（全新）** —— 把多个账号（窗口）编成一组，遇到"操作频繁"限流时，**自动把当前对话转移到组内另一个账号继续**。
2. **手动/自动同链路** —— 组上「转移对话」按钮可手动触发；被限流时自动触发，两者**完全同一条链路**。
3. **切换前先探测** —— 转移前先试探目标账号**是否也被限流**（新开对话发条消息），不通就换下一个。
4. **失败自动退回** —— 组内账号都不可用时，**退回原账号继续重试**，不卡死。
5. **MCP 文档** —— 新增 MCP 配置与使用说明。

## 🪟 窗口组（全新）

侧边栏「窗口」页新增**窗口组**——把多个账号（每个窗口一个登录账号）编成一组，用于**限流轮换**。

- **新建窗口组**：顶部按钮，输入组名即可
- **管理组**：改名、增删组内窗口（按顺序轮换）
- **转移对话**：把当前对话**转移到组内下一个账号**继续
- 组内显示「**最近：xxx**」，点击跳到最近一次继续的窗口与对话

---

## 🔁 自动轮换（限流时）

当某个账号遇到「操作频繁」（HTTP 429 / 限流文案）时：

1. 自动**停止**当前生成与工具调用
2. 把当前对话**全量分享**出去
3. **探测**组内下一个账号是否可用（新开对话发测试消息判限流）
   - 可用 → 在新窗口打开分享链接 → **初始化项目** → 接着干活
   - 不可用 → 探测再下一个
4. 组内账号**都不可用** → 退回原账号**继续重试**

> 手动点「转移对话」走**完全相同的链路**（方便测试）。
