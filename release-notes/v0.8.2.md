# v0.8.2 — Rules 规则 + 自带运行时

> 本次带来 **Rules（规则）**：把项目约束**按文件路径**精准告诉 AI——改哪块代码，才给哪块的规矩。
> 同时 **MCP 的 uvx/npx 现在开箱即用**（自带 uv/node），不用自己装环境。

## ✨ 新增

### Rules 规则（对齐 Claude Code）· 0.8.2

以前给 AI 的项目约束都写在 `ESTRIX.md` 里，**一次性全塞**。现在多了一种更聪明的：**规则**。

- 放在 `.estrix/rules/`（项目里）或 `~/.estrix/rules/`（全局）
- **可以绑定文件路径**——比如"只对 `src/api/**` 生效"

**效果**：AI 改 API 层代码时，才看到"API 的规矩"；改别的，就不打扰它。省上下文、更精准。

```markdown
---
name: api-rules
paths:
  - "src/api/**/*.ts"
---
# API 开发规则
- 所有接口必须校验入参
```

> 不写 `paths` 的规则 = 始终生效（和 ESTRIX.md 一样）。

**完整说明 → [Rules 配置与使用](docs/rules.md)**

### MCP 的 uvx / npx 开箱即用 · 0.8.2

以前配 MCP 时，如果它要 `uvx`（Python 工具）或 `npx`（Node 工具），**得你自己先装好 uv / Node**，否则连不上、还看不出原因。

现在应用**自带了 uv 和 Node**——配了 `uvx`/`npx` 的 MCP **直接就能用**，不用装任何环境。

### MCP 面板显示来源 · 0.8.2

列表里每个 MCP 会标明它是**项目级**还是**用户级**。
